# iPhone Peek Demo

A mobile-friendly, browser-based iPhone-inspired interface demo built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — layout, wallpaper treatment, and animations
- `app.js` — passcode and interaction logic
- `assets/wallpaper.jpg` — wallpaper used on the lock and home screens

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

Demo passcode: `1809`. This is a visual simulation only; it does not unlock or control an actual phone.
